# Example interface

Interface, comparator, sort, List, Stream, ...

## Tech stack

- Java (no build tool: plain source files)

## Concepts covered

Comparator/Comparable, Stream API, collections, console input (Scanner), custom exceptions, exception handling, interfaces, lambda expressions, static/final members.

## Project structure

- `Main`: Main
- `Students`: Mark, Student, StudentComparator, Students
- `Teachers`: ExistException, NotFoundException, Session, Teacher, TeacherComparator, Teachers
- `interfaces`: ICalcul

## How to run

Open the folder in IntelliJ IDEA or Eclipse and run `Main` (it contains the `main` method).
